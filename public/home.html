STEP 01 · PLC LADDER

1. กำหนดตาราง PLC Tags

สร้างชื่อตัวแปรให้ตรงกับโปรแกรม Ladder พร้อมระบุ Address จริง (D100, %IW64, M0.0) และชนิดข้อมูล (BOOL / INT / REAL)

STEP 02 · DATA SOURCES

2. เชื่อม Google Sheets / DB

ดึงข้อมูลจริงจากลิงก์ Google Sheets (CSV), อัปโหลดไฟล์ตาราง .CSV หรือยิง Query เข้า PostgreSQL / MySQL / InfluxDB API

STEP 03 · GRAFANA DESIGNER

3. ออกแบบ & Export JSON

เพิ่มกล่อง Stat, Gauge, Time Series, รูปเครื่องจักร/Robot PNG ตั้งค่า Threshold แจ้งเตือน และส่งออกเป็นไฟล์ .json

🎛️

Panel Options & Thresholds แบบ Grafana

ปรับแต่งกล่องข้อมูลได้ละเอียดทุกจุด ทั้งชื่อ Title, คำอธิบาย, หน่วยวัด, ทศนิยม, ขอบเขตค่าต่ำสุด-สูงสุด (Min/Max), เกณฑ์สีแจ้งเตือนอัตโนมัติ (Warning / Critical Threshold) และการขยายขนาดคอลัมน์ (Grid Span)

✓ Stat & Gauge Panels ✓ Time-Series Trend ✓ Auto Threshold Colors
🦾

โมเดลเครื่องจักร & Robot (.PNG)

นำเข้ารูปภาพเครื่องจักรหรือแขนกล Robot (.PNG) เข้ามาจัดวางคู่กับเกจวัด พร้อมผูกสถานะ RUNNING / STANDBY เข้ากับบิตของ PLC ได้ทันที

🏷️

PLC Tag & Address Mapping

จัดการตารางตัวแปรจากโปรแกรม Ladder ทั้ง Register Address (D100, %MW10) และ Data Type (BOOL / INT / REAL) เพื่อนำไปเลือกผูกในกราฟ

🗄️

เชื่อมตาราง & ฐานข้อมูลจริง

ดึงข้อมูลจริงจากลิงก์ Google Sheets (CSV), ไฟล์ .CSV หรือ REST API ของ PostgreSQL / MySQL / InfluxDB โดยไม่มีการใช้ข้อมูลจำลอง

📤

Export & Import Dashboard (.JSON)

ส่งออกโครงสร้าง Dashboard พร้อมตาราง PLC Tags เป็นไฟล์ .json เพื่อนำไปใช้งานต่อ หรือนำเข้ากลับมาแก้ไขได้ตลอดเวลา
